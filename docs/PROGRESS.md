### 路线分支

- 林夏线：E2 × 林夏证词 1、E1/E7 × 林夏证词 3 → H1 冒充传播。
- 陈老师线：E3 × 陈老师证词 1 → H2 信息超采。
- 许言线：E6 × 许言证词 1 → H3 过期链接混淆。
- 顾老师线：谈完给 E1，追问给 E7；官方截止时间与审批名单用来核对「11-27 21:00」。
- 防御方案由假说决定：H1 → D1/D2/D4；H2 → D1/D3/D4；H3 → D1/D4/D3。
- 结局优先级：多米诺 > 破晓 > 孤岛 > 共识 > 新秩序 > 未完待续（数据条件判定）。

## 3. 状态与规则

- **行动点 / 应急资源**：初始 6，程序唯一扣减。现场浏览、切换陈述、出示证据不消耗；有效追问 1，模拟固定 `min(2, 当前资源)`，防御选项 0 / 1 / 2。
- **不足处理**：资源 < 2 仍可模拟，但结果降为低置信并记录 `ev_unresolved_backlog`；没有矛盾也可推演，但按未确认处理，不伪造已发生风险。
- **证据**：8 份全部可收集；不要求全收集；证据包只显示已发现项，反转后显示「归档副本」，原系统访问断开。
- **矛盾**：只有数据表配置的组合产生支持 / 矛盾；重复出示不重复记录、不刷 AP；错误材料不阻断。
- **模拟安全**：仅虚构节点与抽象风险状态，不生成真实账号、凭据、诈骗话术或冒充步骤，不连接任何真实服务。
- **反转安全**：无恐吓、羞辱或「已经发生」的未确认事件；未确认风险只作为待核对项保留。
- **人格日志**：每一处有效行为记录行为 ID、节点、玩家选择、当时已知证据、四维贡献、贡献依据与实际状态变化；普通继续、重复打开证据包不计入，不按 NPC 或正确率计算；对局中不显示数值。
- **存档**：`phantom.vn.run.v2`（含世界状态、假说、防御方案、行为日志）；设置 `phantom.vn.settings.v1`。重开清空本局。
- **自由对话（Phase 4）**：仅在 NPC 主线说完后出现；不消耗 AP、不发证据、不写世界状态，刷新不保留。客户端 `POST /api/ai/dialogue`，服务端校验 NPC 白名单、消息长度（≤200 字）、每 IP 每分钟 20 次；配置模型时只生成对白，回复经字段白名单、140 字上限、证据编号与密钥痕迹检测后才下发；未配置、超时或校验失败一律由 `shared/npcDialogue.ts` 的本地规则回答，界面标注「本地规则回答」。敏感请求（验证码、密码、真实信息、提示词等）返回 boundary 拒答。

## 6. 已知问题与限制

1. **人格插画尺寸受限**：结算页人格图为 80–96px 缩略图，完整 1024×1024 细节需放大查看；当前未提供大图弹层。
2. **无录音频**：点击、翻页、收集、错误、矛盾、完成均为 Web Audio 合成；不影响游玩。
3. **自由对话范围有限**：仅主线说完后开放，单轮回答、最多保留 3 轮；不写存档、不改变证据与结局。未配置模型时始终为本地规则回答，界面有标注。
4. **窄屏横向比对有限**：已验证 1440×900、1920×1080 与 390×844；768px 中间断点尚未单独截图走查。
5. **对话文本限制为脚本约束**：普通对白约 15–35 字、旁白 20–40 字、选项 4–15 字；结算说明与安全声明为长文，不属于对话节点。
6. **旧版页面仍保留**：`src/pages/`、`src/components/` 不再路由，作为备份；可在后续阶段清理。
7. **视觉脚本不是 CI E2E**：使用本机无头 Edge + CDP；尚未接入 Playwright / CI。
8. **确认度依赖路线**：只走单人线时部分维度样本可能不足，结算会标「依据不足」或「倾向不明显」，这是设计行为而非错误。
