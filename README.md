## 快速开始

环境要求：Node.js 20+（开发时使用 Node.js 24），npm 10+。

```bash
npm install
npm run dev
```

- 前端（Vite）：<http://localhost:5173>
- 本地 API（Express）：<http://localhost:8787>

`npm run dev` 会同时启动两者。无需任何模型配置即可完整游玩当前阶段。

### 模型配置（可选，后续阶段才使用）

服务端从环境变量读取模型配置，**不会下发到浏览器**：

```bash
cp .env.example .env
```

`.env` 中至少包含：

```dotenv
LLM_BASE_URL=https://your-provider.example/v1
LLM_API_KEY=
LLM_MODEL=
PORT=8787
```

- 未配置时，`GET /api/ai/status` 返回 `mode: "demo"`，游戏正常进入本地演示模式；NPC 自由提问由本地规则回答。
- `GET /api/ai/status` 只返回模式、模型名与运行时长，不返回 Base URL 或 Key。
- `POST /api/ai/dialogue` 只接收 `{ npcId, message }`，回复经字段白名单校验；模型只生成对白，不发放证据、不改变状态。未配置、超时或校验失败时自动回退本地规则。
- 服务端不绑定特定厂商；任何兼容 Chat Completions 风格的服务均可通过这三个变量接入。
- 不要把 `.env` 提交到版本库；`.gitignore` 已忽略。

## 当前可玩的闭环（第一章）

1. **序章**：3 句旁白交代倒计时、异常通知与虚构红队授权；点击画面、对话框或按空格继续。
2. **现场调查**：文化节活动室 3 个热区（手机 / 电脑 / 公告板）；点开自动归档，不消耗行动点，只显示已发现的材料。
3. **人物交流**：5 名 NPC 无固定顺序，各自提供不同线索；追问一次消耗 1 行动点，顾老师谈完自动给出官方通知副本。主线说完后可自由提问，不消耗行动点、不发证据；未配置模型时由本地规则回答。
4. **矛盾质询**：林夏 / 陈老师 / 许言三份证词，逐句切换与追问；支持、矛盾、不足、无关四种确定性反馈，重复出示不重复记录。
5. **红队模拟**：选择冒充传播 / 信息超采 / 过期链接混淆；抽象节点逐步展开，固定消耗 2 行动点，只有矛盾支撑才算确认。
6. **身份反转**：4 帧权限失效演出，可跳过；红队标识消失，证据变成只读归档副本，未确认风险不会被写成已经发生。
7. **防御处置**：以普通学生身份完成 3 项灰色决策（渠道、责任、通知、修复中取 3 项），每项 3 个带成本选项，事前不显示数值。
8. **临时结算**：6 结局之一、暂定 Phantom Type、3 条真实行为依据、下一次防守建议与重新体验。

当前 6 结局：破晓、共识、新秩序、孤岛、多米诺、未完待续。结局与人格分别由行为记录判定，互不影响。

## 架构要点

- **引擎与界面解耦**：`src/game/engine` 为确定性纯函数，负责取证、NPC、质询、模拟、反转、防御与结算；`VnApp` 是唯一写入方，场景只派发动作。
- **规则不由模型裁决**：矛盾组合、AP 扣除、世界变化与结局优先级均为程序内固定映射；自由对话中的模型只生成对白，回复经校验后才显示，不改变事实与状态。
- **自由对话可降级**：`POST /api/ai/dialogue` 由服务端限流与校验；未配置模型、超时或回复不合格时使用 `shared/npcDialogue.ts` 的本地规则，界面标注「本地规则回答」。
- **双层舞台**：背景与立绘是独立图层，可分别替换；热区使用百分比坐标，随画面缩放。
- **画框随窗口伸缩**：桌面端场景宽度按视口高度计算（16:9，最大 1560px），与全屏封面衔接，不再固定小窗。
- **交互克制**：普通对话不挂功能按钮；追问、出示、进入模拟、防御选项等只在对应节点出现；证据包是顶栏常驻入口。
- **可访问与减动效**：热区支持触控与键盘焦点；「减弱动画」会关闭推镜、打字机与冲突演出位移；音效可静音。
- **无模型可运行**：模型配置只存在于服务端环境变量；缺失配置时明确降级为本地 demo，自由提问也由本地规则回答，不影响完整游玩。
- **虚构隔离**：演练数据全部来自静态预设；不连接真实系统，不收集真实敏感信息，不生成现实可用的攻击步骤或凭据。

安全与合规设计详见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 部署说明

```bash
npm run build
```

`dist/` 为纯静态前端，可部署到任意静态托管；`server/` 为独立 Node 服务，用于状态查询与后续 NPC 对话。生产环境需自行配置反向代理将 `/api` 指向服务端，并通过环境变量注入模型配置。**不要**把模型 Key 写入前端构建变量或提交到仓库。

`public/assets/` 为本地素材，构建后随 `dist/` 一起发布，不依赖远程图片服务。
